<h1><strong>Getting Started With HTML</strong></h1>

<h2><strong>Descrição</strong></h2>
<p align="justify">
  Este repositório foi criado com o objetivo de desenvolver uma página web simples, utilizando as principais tags HTML aprendidas no primeiro módulo da formação de HTML. Consolidando o conhecimento adquirido, explorando diferentes tags e suas funcionalidades. 
</p>

<h2><strong>Tecnologias Utilizadas</strong></h2>
<ul>
  <li align="justify"><a href="https://developer.mozilla.org/pt-BR/docs/Web/HTML"><strong>HTML</strong></a>: Linguagem de marcação utilizada para estruturar a página web.</li>
  <li align="justify"><a href="https://code.visualstudio.com/"><strong>VS Code</strong></a>: Editor de código utilizado para escrever o HTML.</li>
  <li align="justify"><a href="https://www.google.com/intl/pt-BR/chrome/"><strong>Navegador (Chrome)</strong></a>: Para visualizar a página em tempo real.</li>
</ul>

<h2><strong>Estrutura do Projeto</strong></h2>
<p align="justify">A estrutura do projeto é organizada da seguinte forma:</p>

```plaintext
/
├── index.html
├── README.md
```

<h2><strong>Notas</strong></h2>
<ul>
  <li align="justify">Organizei o conteúdo com títulos <strong><em>h1 a h6</em></strong> para hierarquia textual.</li>
  <li align="justify">Usei <strong><em>mark, del, abbr, sup e sub</em></strong> para enriquecer o conteúdo.</li>
  <li align="justify">Pratiquei listas ordenadas e não ordenadas, com links e divisões de seção.</li>
  <li align="justify">Explorei tags não semânticas para compreender sua finalidade.</li>
</ul>
